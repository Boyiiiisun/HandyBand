## Download and run

Download **HandyBand-v1.0.1-windows-x64.zip**, extract the entire archive, and
double-click **HandyBand.exe** inside the HandyBand folder. Keep the other files
alongside it. Python, dependencies, hand/pose models, and the published audio
are included. No Python installation or virtual-environment setup is required.

Requires 64-bit Windows, a webcam and audio output. This release is unsigned.

## Source checkout

Double-click **Start HandyBand.cmd**. The first launch needs internet and
automatically prepares uv, Python 3.12, locked dependencies and verified models.
Later launches reuse the environment. After `git pull`, launch the same file.

Interstellar includes the existing guided gesture exercise; the locally imported
Cornfield Chase score and MIDI are not distributed.

## Validation

Also fixes the alternate gesture-3 mapping and updates the timing regression
test to the existing 750 ms repeat interval.

The release build runs the test suite, lint, and a packaged self-test exercising
both MediaPipe models, inference on a blank frame, and all styles using dummy
audio. Physical camera tracking and audible playback still depend on the device.
